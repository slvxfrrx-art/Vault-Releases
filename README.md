# Vault

Current version: `1.0.4` Stable.

Vault is the current branding of the application formerly referred to as Password Systems Vault.

Vault is a secure local desktop vault built with Tauri 2, React, TypeScript, Rust, and SQLite. It is designed for storing local systems information, VPNs, connections, users, credentials, attachments, and operational notes on a Windows desktop without cloud sync.

Versione 1.0.4 Stable is stable for local use, but it has not been professionally audited. Review and test the app and the operating environment before using it for critical production credentials.

## Purpose

The app provides a local-first vault for password and systems administration workflows. It keeps vault data on the user's machine, supports encrypted sensitive fields, and includes backup/restore tools for local data recovery.

## Main Features

- Local desktop vault with master password.
- Tree organization for folders, systems, VPNs, connections, and credentials.
- VPN management, including primary certificate handling.
- System connections with multiple connection users.
- Generic credentials.
- Password reveal, copy, and password history.
- Encrypted attachments while stored inside the vault.
- Node logos.
- Local backup, restore, and safety backup before restore.
- Google Drive backup and restore for encrypted `.vaultbackup` files when OAuth is configured, including optional auto-upload policies.
- Settings for autolock and clipboard cleanup when enabled.
- Search over safe metadata.
- Security audit helper using fake markers.
- Factory reset for local vault data.
- Windows installer generated by Tauri.
- Signed Tauri updater support when a real updater key and GitHub Releases manifest are configured.

## Security Model

- The master password is not stored.
- The runtime vault key is derived from the master password and vault metadata.
- Sensitive fields are encrypted before being persisted.
- Backup files contain encrypted vault data and must still be protected by the user.
- Losing the master password may make vault data unrecoverable.
- Malware or remote-control software on an unlocked machine can read secrets while the vault is unlocked.
- Clipboard contents can be read by other apps while a password is copied.
- Exported attachments are plaintext outside the app.
- Update checks do not send vault data, backup data, machine IDs, usernames, Google Drive tokens, or telemetry.
- Signed updater packages are verified by Tauri before installation.
- This project does not claim enterprise-grade security or audited cryptography.
